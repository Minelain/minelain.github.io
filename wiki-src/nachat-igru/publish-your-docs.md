# Как зайти на сервер

Вы можете зайти с Bedrock или  Java версии игры.<br>

Для игры на Java версии вам понадобиться любой лаунчер Minecraft. Например — TLauncher или KLauncher. Используйте версию 1.19.4 - 26.2 В главном меню нажмите на вторую кнопку "Сетевая игра". Далее нажмите снизу кнопку "Добавить" и в поле "Адрес сервера" впишите minelain.zapto/org



Для игры на Bedrock версии вам нужен любой клиент поддерживающий Minecraft Bedrock версии 26.0 - 26.30. В главном меню войдите в пункт "Сервера" нажмите кнопку добавить и в поле IP впишите адрес сервера minecampff.zapto.org



**Поддерживаемые версии игры:**

Java: 1.19.4 - 26.2

Bedrock: 26.0 - 26.30

**Айпи и порт:**

**Java:** minelain.zapto.org

**Bedrock:** minelain.zapto.org **Порт: 19132**
