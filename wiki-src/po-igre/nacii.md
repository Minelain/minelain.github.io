# Нации

Нацию может создать город с титулом **Деревня**. Для этого титула нужно **4 жителя и 7.5k дублонов**\
\
**В чем смысл наций и их бонусы? Нации заставляют города объединяться в нации чтобы получать бонусы, как пример эффекты на территории нации**

Также при прокачки нации повышаются лимиты и бонусы:

<figure><img src="https://i.ibb.co/KBsXtBw/Screenshot-20260716-173548.png" alt="" width="563"><figcaption></figcaption></figure>

Также нация помогает в случае войны своему городу на который напали.

| Команда                | Для чего                                    |
| ---------------------- | ------------------------------------------- |
| `/n`                   | Меню управление нацией                      |
| `/n list`              | Посмотреть все существующие нации           |
| `/n info <Нация>`      | Посмотреть информацию о нации               |
| `/n create <Название>` | Создать нацию                               |
| `/n delete`            | Удалить нацию                               |
| `/n rename <Название>` | Сменить название нации                      |
| `/n setcapital`        | Сменить столицу нации                       |
| `/n trust <Город>`     | Пригласить город в нацию                    |
| `/n untrust <Город>`   | Убрать город из нации                       |
| `/n level`             | Посмотреть уровень прогресса развития нации |
| `/n spawn`             | Телепорт на спавн столицы нации             |
| `/n leave`             | Уйти из нации будучи городом                |
| `/n accept <Нация>`    | Одобрить вступление в нацию будучи городом  |
| `/n deny <Нация>`      | Отказать вступление в нацию будучи городом  |
| `/n relations`         | Управление отношениями нации                |
| `/n menu effects`      | Открывает эффекты на уровне нации.          |
| `/n menu taxes`        | Открывает доступ к национальным налогам.    |
