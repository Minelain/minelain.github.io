# Города

### Как создать город и управлять им?

#### **Создание города**

Встаньте на место будущего города и введите команду `/l create <Название>`.\
Требования для создания: **16 досок, 32 булыжника, 6 хлеба**.

#### Расширение территории

Увеличить площадь города можно тремя способами:

* Вручную по чанкам: Нажмите F3 + G для отображения границ. Зайдите в нужный чанк и введите команду `/l claim`.

<figure><img src="https://i.ibb.co/twyMDj7t/Screenshot-20260715-200037.png" alt="" width="563"><figcaption></figcaption></figure>

* Выделением зоны: Введите `/l selection` и выделите два противоположных угла нужной территории, затем пропишите `/l claim`. Если хотите заприватить квадрат по всей высоте мира, предварительно используйте команду `/l selection expand`.
* Через интерактивную карту (Только для Java-игроков): Введите `/l map` и приватьте нужные чанки левым кликом мыши (ЛКМ).

<figure><img src="https://i.ibb.co/dJjqnfWN/Screenshot-20260715-195443.png" alt="" width="563"><figcaption></figcaption></figure>

#### **Управление участниками и ролями**

Роль определяет права игрока на территории. Быстрое управление осуществляется командами:

* Добавить игрока: `/l trust <Ник>`
* Удалить игрока: `/l untrust <Ник>`
* Изменить роль: `/l setrole <Ник> * <Роль>`

#### **Экономика и налоги**

Город ежедневно выплачивает серверу налог — 2 монеты за каждый заприваченный чанк (текущее количество чанков можно посмотреть в статистике города). Чтобы покрывать эти расходы, вы можете установить внутренний налог для жителей.

* Пополнить казну города: `/l deposit <сумма>`
* Снять деньги из казны: `/l withdraw <сумма>`

#### **Интерфейс управления городом (Настройки, Флаги и Налоги)**

Детальная настройка города (включая защиту от чужаков, ПВП и внутренние налоги) происходит через графический интерфейс. **/l**

| **Раздел**                       | **Путь в меню для Java Edition**                                      | **Путь в меню для Bedrock Edition** |
| -------------------------------- | --------------------------------------------------------------------- | ----------------------------------- |
| Участники (Добавление/Удаление)  | `Управление игроками > Участники` _(ЛКМ по зеленому/красному бетону)_ | `Управление игроками` > `Участники` |
| Роли (Настройка прав жителей)    | `Роли`                                                                | `Настройки` > `Роли области`        |
| Права                            | `Природные настройки` _(настройка прав через ЛКМ)_                    | `Настройки` > `Флаги области`       |
| Налоги (Сбор монет с участников) | `Налоги`                                                              | `Настройки` > `Налоги области`      |

#### **Аренда.** <a href="#komandy" id="komandy"></a>

Приваты очень настраиваемые и вы можете ограничить весь доступ к привату даже жителям, дав им возможность взаимодействовать только в определенных участках за аренду.\
Пропишите `/l menu here`, или же просто `/l`, выберите меню аренды. Установите цену, время и другие. Подвердите предложение и любой житель сможет купить землю в аренду!
